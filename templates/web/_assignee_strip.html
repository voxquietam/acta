{% load i18n %} {% comment %} Page-top assignee strip — horizontal scrollable row of avatar chips, no sticky pinning. The native scrollbar is hidden; each edge shows a fade gradient + ``+N`` counter overlay when content is scrolled past it. The chips themselves live in ``_assignee_chips.html`` so the facet endpoint (``web:filter_facets``) can re-render just that block on a filter change and the client morphs it in. Selection model (single-click pick, Cmd/Ctrl to add, right-click to exclude) and the optional per-chip count badge are documented there. {% endcomment %}
