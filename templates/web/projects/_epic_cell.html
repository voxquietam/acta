{% load i18n %} {% load lucide %} {% comment %} Epic cell — puts the task under an epic, or takes it out. Same click-to-edit + teleported dropdown pattern as the cycle / size cells. Deliberately a separate row from Parent: a subtask keeps its parent and may still belong to an epic, and unlike a parent the epic may live in **another project** of the same workspace — which is the whole reason epics exist. See docs/decisions/0036-epics.md. The list is the workspace's epics with their progress, so a person picking one can see which is nearly finished without opening it. Posts to ``set_task_epic`` and swaps this cell. Expects ``task`` and ``workspace_epics`` (rows carrying ``member_done`` / ``member_total``). {% endcomment %}
