{% extends "base_app.html" %} {% load i18n %} {% load web_extras %} {% load lucide %} {% comment %} An epic's page is its board (design "Epics Rethink", artboard 1d with the Blocked lane from 1c). Not the task page with a different rail: an epic has no status, size or due date of its own — it reads them off the tasks it collects — so that rail would be mostly locked values, and the tasks are what a person opened the epic for. Columns are the six working statuses. A blocked task **keeps its status column** and rises into its own lane at the top of it, so the board still answers "how far along is this" while saying what is stuck — moving it to a Blocked column would lose the first answer to tell you the second. Details (description, attachments, comments, properties) live in a panel on the right, opened from the topbar, so the board keeps the full width by default. Expects ``epic_columns`` / ``epic_projects`` / ``epic_done`` / ``epic_total`` / ``epic_pct`` / ``epic_start`` / ``epic_end`` from ``_epic_board_context``.
