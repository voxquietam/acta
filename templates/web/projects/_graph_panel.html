Built by ``_graph_context`` in apps/web/views.py, drawn by static/js/graph.js. See docs/decisions/0033-relationship-graph.md. The payload carries EVERY live task, with ``connected`` telling the two apart; the toggle below reveals the isolated ones without another request. Default is connected-only, because a project's unlinked tasks are the majority and drawing them turns the view into confetti. ``data-task-graph`` is the marker the loader in base.html watches — dagre is injected only once this panel exists, the same way the description editor bundle is handled.
