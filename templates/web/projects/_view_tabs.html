{% load i18n %} {% load lucide %} {% comment %} Project view tabs (Overview / Kanban / Table / List). Lives in the topbar ``topbar_mid`` block on the project detail page, so the active tab is visible regardless of scroll. Clicking a tab updates the ``viewMode`` Alpine store and pushes the new ``?view=`` URL via ``history.pushState`` — no full nav, no HTMX request. The tabs' highlighted state is data-bound to the store so reverting via browser back/forward keeps the active tab in sync. Below ``2xl:`` the tabs keep their icon and drop the label, which the tooltip carries instead. Eight labelled tabs are ~716px wide, and with the sidebar open the topbar runs out of room below a ~1500px viewport — the right-hand icons then go past the edge. The strip is the only section that can give: the heading truncates to nothing long before it matters, and the right is icons at a fixed size. Layout per ``acta-design-system/preview/comp-tabs.html`` — segmented pill: card-coloured wrapper with thin padding holds each tab; the active tab is brand-tinted with a 1px inset ring and Lucide icons. Disabled placeholders (Timeline; Overview on All Tasks) keep the slot visible with a ``lock`` glyph. {% endcomment %}
{% comment %} Mobile view picker — a single dropdown trigger that shows the active view's icon + label + chevron. Replaces the segmented pill below ``sm:`` because 5-7 tab buttons don't fit alongside hamburger + heading + action icons on a 393 px iPhone. The dropdown menu lists every view available on this page (gated by ``allow_backlog`` / ``allow_overview`` just like the desktop tabs). Selecting one mirrors the desktop ``@click.prevent`` flow: ``$store.viewMode.set`` + ``history.pushState`` (no full nav). {% endcomment %}
