{% load i18n %} {% load lucide %} {% load web_extras %} {% comment %} Where this epic's work sits — the one question an epic exists to raise. An epic stores no milestone of its own; it derives the set from its tasks, the way it already derives dates and progress (ADR 0037), so an epic spread across three dates is normal and reads as normal here. A bar proportioned by how many tasks sit in each date, then a row each: the milestone's own state, this epic's share of it, and how much of that share already runs past the date. The share and the state are different numbers on purpose — an epic finishing its three tasks does not make the milestone complete. Expects ``epic_milestones`` from ``apps.milestones.services``.
