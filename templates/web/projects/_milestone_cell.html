{% load i18n %} {% comment %} Milestone cell — commits the task to a milestone, or takes it out of one. Same click-to-edit + teleported dropdown pattern as the cycle / size cells. Expects ``task`` and ``project_milestones``. The picker only offers milestones whose scope covers this task's project: a milestone can be shared across projects, and that scope is what makes the sharing mean something. Closed milestones are left out — see docs/decisions/0037-milestones.md. An epic has no cell at all. It derives its milestones from the tasks it collects, the way it already derives its dates and its size, so the rail hides the row rather than offering a control that would be refused. {% endcomment %}
