A grid and not a list on purpose: an epic's own state is read off the tasks it collects, so the question worth answering on a page that shows all of them is *where the work has collected*. A dark cell is a column work is piling up in, and that reads across six epics without opening anything. Six columns, not seven: ``cancelled`` is out for the same reason it is out of ``Task.epic_members`` — it is not work any more.
